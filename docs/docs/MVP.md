# Project Phantom - MVP

## Version

v0.1

## Goal

Build a tool that analyzes a Python project and presents
basic information about its structure and code.

## Input

A local project folder.

## Features

- Scan project files
- Detect Python files
- Count files
- Count functions
- Count classes
- Detect imports
- Display project structure
- Display basic statistics

## Initial Language Support

Python

## Output

A project analysis dashboard containing:

- File statistics
- Python statistics
- Imports
- Project structure

## Not Included in v0.1

- AI
- 3D visualization
- Security analysis
- Multi-language support
- Cloud deployment

## Success Criteria

A user can provide a Python project and receive
a useful analysis of its structure and basic code statistics.
