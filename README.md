# Project Phantom 👻

An AI-powered software archaeology tool that helps developers
understand unfamiliar codebases.

## Vision

Turn a complex codebase into something a developer can
understand, explore, and investigate.

## Planned Features

- Codebase analysis
- Project structure visualization
- Dependency graph
- AI-powered codebase explanation
- Automatic documentation
- Security analysis
- Interactive 3D code visualization
